## App Overview

| App | Version | Purpose | Format |
|-----|---------|---------|--------|
| **ClassMate** | 2.0 | Classroom management & interactive learning | HTML (1.9 MB) |

## How to Use

### Running the Apps
1. Download the `.html` file
2. Open in any web browser (Chrome, Safari, Firefox)
3. No installation needed — fully self-contained

### ClassMate 2.0
- Interactive classroom tool
- Student engagement activities
- Real-time feedback

### Sightword Universe 4.4
- Space-themed sight words adventure
- Progressive difficulty levels
- Gamified learning experience

## Technical Notes

- Apps are HTML5-based (self-contained)
- No internet connection required to run
- Works on desktop and tablet browsers
- Fully playable offline
