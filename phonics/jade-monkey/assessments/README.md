# Jade Monkey Assessments

Phonics and sight words assessments for K3 ESL learners.

## Assessment Overview

| Assessment | Type | Level | Purpose | Format |
|-----------|------|-------|---------|--------|
| **Atlantis Level 1.2** | Sight Words | 1 | Letter & word recognition | PDF |
| **Candyland Sightwords Level 2.3** | Sight Words | 2 | Word reading & comprehension | PDF |
| **F1 Sightwords v1.3** | Sight Words | 1 | Foundation sight words | PDF |
| **Fighter Plane Blending 1.5** | Blending | 1 | Sound blending & phoneme awareness | Interactive HTML |
| **GhostMountain Level 3 1.2** | Sight Words | 3 | Advanced sight word application | PDF |
| **Rocket Letters 1.0** | Letter Recognition | 1 | Letter naming & formation | Interactive HTML |

## How to Use

### Quick Access
- **Level 1 assessments:** Atlantis, F1 Sightwords, Rocket Letters, Fighter Plane Blending
- **Level 2 assessments:** Candyland Sightwords
- **Level 3 assessments:** GhostMountain

### For Interactive Assessments
- Fighter Plane Blending 1.5.html — Open in browser
- Rocket Letters 1.0.html — Open in browser

### For PDF Assessments
- Print or view digitally
- Can be annotated in PDF reader

## File Organization

Keep files organized by version number (e.g., Level X.Y format) for easy tracking of assessment iterations.

## Adding New Assessments

When adding new assessments:
1. Use naming convention: `[Name] [Type] [Version].ext`
2. Update this README with new entry
3. Commit with descriptive message
