# ESL Teaching - K3

K3 (ages 3-4) English language instruction at an IB school in Hangzhou.

## Current Work

**Summer 2026 Curriculum:** Pre-Primer Sight Words (Lavinia Pop handwriting program)

Weekly rotation through: a, are, at, away, big

Each lesson: letter tracing → word tracing → word writing → sentence completion with illustrations

## Challenge

Students find worksheets repetitive. Need to add engagement (movement, games, dramatization) without adding complexity or energy load.

- **activities/** — Games, movement-based learning, dramatization scripts
